# International Women in AI Day (1 October 2026)

A co-branded graphic from **Nuovo Insights** and **Macarthur Women Redefining AI** to celebrate International Women in AI Day.

## What's in here

| File | What it is | Size |
|---|---|---|
| `exports/square.png` | Square post | 1080 × 1080 (Instagram, Facebook, LinkedIn) |
| `exports/linkedin.png` | LinkedIn landscape post | 1200 × 627 |
| `designs.html` | The editable design file (open it in any web browser) | |
| `render.js` | Turns the designs into the PNG images above (`node render.js`) | |

The logo and fonts are shared with the `../un-women-ai-hub/` pack, so both campaigns look like one family.
